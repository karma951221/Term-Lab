# 관계정보 화면기획

> 상태: 초안 · 최종수정: 2026-09-07
>
> 대응 기획: [[문면_기획]] 「참조 무결성 — 참조는 그래프다」

## 목적

**바꾸기 직전에 「이걸 건드리면 어디까지 파장이 가나」를 그림 한 장으로 본다.**

관계정보 화면은 지금 정방향·역방향 참조를 **목록**으로 준다. 목록은 정확한 좌표를 주지만
「이 공용조항이 세 상품의 일곱 문서에 걸쳐 있다」 같은 **모양**은 머리로 재구성해야 한다.
그림은 그 모양을 준다. 둘은 서로를 대체하지 않으므로 **한 화면에 같이 둔다** — 위에 그림, 아래에 목록.

그림은 **전체 지도가 아니다.** 조회 대상 하나를 중심에 놓은 **이웃 그래프**(local graph)다.
`RefGraph` 전체는 노드 수천 개라 한 판에 그리면 아무것도 읽히지 않고, 「영향 반경」이라는 목적에도
전체 지도는 답하지 않는다.

## 화면 구성

관계정보 화면의 순서 (그래프 패널만 새것, 나머지는 그대로):

```
규모 한 줄  (참조 노드 N 개 중 고아 M · 참조 E 건 중 깨짐 B · 순환 C)
조회 폼
─ 조회 대상이 있을 때만 ────────────────────
[새것] 이웃 그래프 패널
정방향 — 이것이 참조하는 것       (목록, 기존)
역방향 — 이것을 참조하는 것       (목록, 기존)
옵션 오버라이드 사용처            (목록, 기존)
깨진 정방향 참조                  (목록, 기존)
──────────────────────────────────────────
고아 / 순환 / 깨진 참조           (기존)
```

### 그래프 패널

```
┌─ 이웃 그래프 ─────────────── 노드 24 / 1,180 · 간선 31 / 4,062 ─┐
│ 깊이 [1] 2  3   방향 [양방향] 역방향만  정방향만   [맞춤]        │
│ 종류 ☑구분자 ☑공용조항 ☑문면 ☑담보 ☑상품 …                      │
│ 형태 ☑본문 참조 ☑구조 결합 ☐부착·타입·탑재 ☑포함 관계          │
├───────────────────────────────────────────────────────────────┤
│                                                               │
│                     (SVG 그림판)                               │
│                                                               │
├───────────────────────────────────────────────────────────────┤
│ 범례: ○ 정의류  □ 문면류  ◇ 모델링류 │ ── 본문 참조 ─ ─ 구조 결합│
└───────────────────────────────────────────────────────────────┘
```

카운트에는 늘 분모가 붙는다 (디자인원칙 §9.6) — 분모는 **필터 적용 전 전체 그래프**의 노드·간선 수다.

### 노드

**종류는 「모양 + 테두리 색」으로 이중 부호화한다.** 색만으로 종류를 말하지 않는다 (§1.2 · §10 Q1).

| 모양 | 묶음 | `RefNodeKey.kind` |
|---|---|---|
| 원 ○ | 정의류 | discriminator · field · enum · enumValue · attribute · attributeValue |
| 사각 □ | 문면류 | document · article · clause · clauseOption · clauseOptionValue · appendix |
| 마름모 ◇ | 모델링류 | coverageNode · product · productCoverage · entity |

- 채움은 `surface` 고정, 종류는 **테두리 색**(`--ts-graph-*`)으로 말한다 → [[ADR-0028-관계정보-그래프뷰]]
- **조회 대상**(중심) = `mark` 채움 + 2px 테두리. 화면 안에서 `mark` 는 여기에만 쓴다 (§1.3 「현재 위치」)
- **선언되지 않은 대상**(깨진 참조의 도착점) = `error` 색 점선 테두리 + 라벨 뒤 「(없음)」
- 라벨은 `describeKey(key, graph)` 경로의 **마지막 마디**만 (「제2조(보험금의 감액지급)」).
  전체 경로 「일반상해사망 특별약관 › 제2조(보험금의 감액지급)」는 `title` tooltip 과 호버 때.
  라벨이 길면 14자에서 자르고 말줄임표. 표시명이 없으면 목록과 같은 규칙으로 코드·id 로 떨어진다 (ADR-0022).

### 간선

화살표는 **참조하는 쪽 → 참조되는 쪽**. 형태(`EdgeVia`)는 색이 아니라 **선 스타일 3종**으로 묶는다 —
15종을 15색으로 칠하면 색 수프가 된다 (§1.3).

| 선 | 묶음 | `EdgeVia` |
|---|---|---|
| 실선 ── | 본문이 값을 읽는 참조 | when · slot · expression |
| 파선 ─ ─ | 구조 결합 | clauseRef · optionSelect · articleRef · link · appendixRef · generalDocument · document · override |
| 점선 ⋯ | 참조가 아닌 관계 | attach · type · mount · combination |
| 가는 회색 선 (화살표 없음) | **포함 관계** | 간선이 아니라 `RefNodeInfo.parent` — 조 ⊂ 문서 · 필드 ⊂ 구분자 · 값 ⊂ enum |

**포함 관계를 안 그리면 그림이 끊어진다.** 문서를 조회했는데 참조는 그 문서의 *조*에 달려 있으면,
조 노드는 문서와 이어지지 않은 채 떠 버린다. 그래서 그림에 들어온 노드는
**이미 그림에 있는 가장 가까운 조상**과 가는 회색 선으로 잇는다 (중간 조상은 넣지 않는다).
포함 선은 홉을 만들지 않는다 — 홉은 참조 간선만 센다.

- 같은 쌍·같은 묶음의 간선 여러 건은 **한 선으로 묶고 「×3」** 을 선 가운데 적는다.
  호버하면 그 안의 형태 이름(`VIA_LABEL`)과 좌표가 tooltip 으로 나온다.
- **깨진 간선**은 `error` 색. 도착점 노드도 error 점선이므로 색만으로 말하지 않는다.
- 자기 참조(순환의 최소형)는 노드 위쪽 고리로 그린다.

### 배치

**물리 시뮬레이션을 쓰지 않는다. 결정적 동심원 배치다** → [[ADR-0028-관계정보-그래프뷰]]

- 중심 = 조회 대상. 링 k = 중심에서 k 홉 떨어진 노드.
- 링 k 의 노드는 (종류 순서 → `nodeKey` 사전순)으로 정렬해 각도를 균등 배분한다. 시작각 −90°(12시).
- 링 반지름 `r(k) = max(120·k, 44·n(k)/2π)` — 노드가 많으면 링이 벌어져 최소 간격 44px 를 지킨다.
- 포함으로 딸려온 조상 노드는 자식 중 가장 작은 홉을 물려받는다.
- `viewBox` 는 노드 bounding box + 여백 40.

같은 대상을 다시 열면 **늘 같은 그림**이 나온다. 어제 본 그림과 오늘 본 그림을 눈으로 비교할 수 있고,
스냅샷 테스트가 가능하다.

## 조작과 상태 전이

| 조작 | 결과 |
|---|---|
| 노드 클릭 | 그 노드가 새 조회 대상이 된다. URL(`?kind=&code=&id=&depth=&dir=&kinds=&vias=`)이 갈리고 서버가 다시 그린다. 조회 폼 값도 따라 바뀐다 |
| 노드 호버 | 그 노드에 붙은 간선과 상대 노드만 진하게, 나머지는 `opacity .25`. 전체 경로 tooltip |
| 간선 호버 | 그 간선의 형태 이름 + 좌표 tooltip |
| 휠 | 줌 (`viewBox` 만 바뀐다) |
| 드래그 | 팬 |
| 「맞춤」 | 줌·팬 원복 |
| 깊이 · 방향 · 필터 | GET 폼 제출 — URL 에 남는다. 링크로 공유되고 뒤로가기가 산다 |

- **노드를 손으로 끌어 옮기지 않는다.** 배치는 데이터가 정하고 사람은 보기만 한다.
- 상세 화면들의 기존 「관계정보 →」 링크는 그대로다. 넘어오면 그림이 딸려 온다.

기본값: 깊이 **1** · 방향 **양방향** · 종류 전부 · 형태는 **본문 참조 + 구조 결합만**(부착·타입·탑재·조합은 꺼짐) · 포함 관계 **켬**.
꺼둔 형태는 「참조가 아닌 관계」라 영향 반경을 부풀린다 — 필요할 때 켠다.

## 예외 · 빈 상태 · 오류

| 상황 | 화면 |
|---|---|
| 조회 대상 없음 | 그래프 패널이 아예 없다 (기존 목록도 없는 것과 같다) |
| 이웃 0건 | 중심 노드 하나만 그리고 「연결된 것이 없다」 |
| 상한 초과 (노드 300 · 간선 600) | **그리지 않는다.** 「이웃이 노드 812개다 — 깊이를 줄이거나 종류를 걸러라」 + 한 단계 낮은 깊이 링크. 부분만 그려 거짓 안심을 주지 않는다 |
| 삭제된 대상(참조만 남음) | 중심을 error 점선으로. 제목은 기존과 같이 「… — 삭제된 대상, 참조만 남았다」 |
| JS 꺼짐 | **그림은 그대로 보인다.** 서버가 좌표까지 계산해 SVG 로 보내기 때문. 줌·팬·호버 강조만 죽고, 노드 클릭은 `<a>` 라 살아 있다 |

## 다루지 않는 것

- **전체 그래프 한 판**(옵시디언 global graph). 목적이 영향 반경이라 필요 없고, 수천 노드는 읽히지 않는다.
- **이력일자 기준 시점 조회.** [[ADR-0026-이력개정-이력일자-작업본확정]] 구현 뒤에 기준일 D 를 `loadGraph` 에 넘기면
  그래프도 자동으로 따라온다. 지금은 작업본 한 시점만 본다.
- **그림 위에서의 편집.** 그림은 읽기 전용이다.
- 노드 접기·펼치기(집계 노드). `RefGraph` 를 1:1로 그린다 — 변환층을 두지 않는다.

## 인수기준

1. 공용조항 하나를 조회하면 그 공용조항을 참조하는 문서·조가 1홉 링에 나타나고, 노드를 클릭하면 그 노드로 조회 대상이 바뀐다.
2. 깨진 참조가 있는 대상을 조회하면 도착점이 error 점선 노드로, 간선이 error 색으로 그려진다.
3. 깊이를 2로 올리면 URL 에 `depth=2` 가 남고, 뒤로가기로 1 로 돌아온다.
4. 노드 300개를 넘기면 그림 대신 안내와 낮은 깊이 링크가 나온다.
5. 같은 대상을 두 번 열면 픽셀이 같다 (레이아웃 스냅샷 테스트).
6. JS 를 끈 브라우저에서도 그림과 노드 링크가 동작한다.
