## 1. 상세 · 수정 화면 (`/coverages/<id>`)

### 목적

담보 마스터 하나를 본다 — 어떤 구조(세부보장 › 급부)이고, 각 층이 어떤 값을 갖는지. 담보속성 · 상품 문맥은 여기 없다.
그건 상품모델링([[상품탑재_화면기획]])의 일이다.

### 화면 구성 — 헤더 + 탭

```
┌──────────────────────────────────────────────────────────────┐
│ ← 담보 목록                                                    │
│ 수술비                                       [✕] [편집] [🗑]  │  헤더 — 편집 흐름 (L2)
├──────────────────────────────────────────────────────────────┤
│ [기본]  담보  세부보장  급부                                    │  탭
├──────────────────────────────────────────────────────────────┤
│ (탭 본문)                                                     │
└──────────────────────────────────────────────────────────────┘
```

| 탭 | 무엇 | 편집 모드에서 |
|---|---|---|
| **기본** | 담보명 · 설명 · 담보약관 문면 링크 · 사용처(탑재 상품담보 N) · **구조 트리(읽기 전용)** | 담보명 · 설명 · 세부보장명 · 급부명만. **구조(추가 · 삭제 · 순서)는 못 바꾼다** — 생성 화면(§2)에서만 |
| **담보** | 담보 레벨에 부착된 구분자의 값 | 값 입력 · 선택적 부착 + / 해제 |
| **세부보장** | 세부보장마다 부착된 구분자의 값 | 위와 같음, 세부보장 단위 |
| **급부** | 급부마다 부착된 구분자의 값 | 위와 같음, 급부 단위 |

- 탭은 **객체(층) 단위**로 가른다. 한 객체의 필드를 탭으로 쪼개지 않는다 — 그건 L2 「한눈에」 위반이다.
- 편집 흐름은 [[02_UI/디자인원칙]] §2 L2 그대로 — 읽기 기본, 우측 상단 「편집」 → 「저장」(변경 시 활성) → 저장 중 disabled.
  **탭을 옮겨도 편집 모드와 변경분은 유지**된다. 저장 하나가 네 탭의 변경을 다 담는다. 변경이 있는 탭 이름에 점(•) 표시.
- 🗑 = 담보 삭제 — 확인 팝업에 하위 세부보장 · 급부 · 값 행 · 탑재 상품담보 건수 (§9.5). 탑재분 · 문면 참조가 있으면 거부 + 목록 (액션 「담보 삭제」).
- **코드(`CVR-0007`)와 상태(미사용 · 적용 · 확정)는 안 그린다** — 담보 마스터 스키마에 둘 다 없다
  (상태는 [[02_UI/디자인원칙]] §10 Q19). 도메인에 없는 값을 화면이 지어내지 않는다 — 담보 조회도 같은 판단이다.
  헤더에 실제로 서는 것은 **탑재 상품담보 N** 하나다. 스키마가 생기면 그때 자리를 준다.

### 기본 탭

```
담보명    [수술비              ]     사용처   탑재 상품담보 3
설명      [                    ]     문면     수술비 담보약관 열기 →

구조                                    구조는 생성할 때 정한다 ⓘ
  수술비
  ├ 1  1종수술                    급부 1
  │    └ 1  수술급여금
  ├ 2  2종수술                    급부 1
  │    └ 1  수술급여금
  └ 3  3종수술 …
```

- 왼쪽 그리드(라벨 120px) + 오른쪽 사용처 · 문면 — 구분자 상세와 같은 좌우 배치 ([[구분자_화면기획]] §2).
- **구조 트리는 들여쓰기 + 순번**으로 그린다. 담보 › 세부보장 › 급부 세 층이 한눈에 보여야 한다 — 지금 화면의 링크 나열로는 안 보인다.
  각 행은 이름 · (세부보장이면) 급부 수. 클릭하면 해당 탭의 그 노드로 이동한다.
- 편집 모드에서 트리의 **이름은 인라인 입력**이 된다 (액션 「담보명 수정」 · 「세부보장명 수정」 · 「급부명 수정」 — 형제 중복 거부).
  추가 · 삭제 · 순서 조작은 **없다.** 트리 머리에 ⓘ 「구조(세부보장 · 급부의 추가 · 삭제 · 순서)는 담보를 만들 때 정한다」.
- 담보명에 담보속성 값(기본계약 · 추가 · 갱신형 · 비갱신형 …)이 들어가면 저장 시 경고 — 「담보속성은 상품에 탑재할 때 정한다」 (거부가 아니라 경고 — Q-C).

### 담보 · 세부보장 · 급부 탭 — 레벨별 특성

```
┌───────────────┬──────────────────────────────────────────────┐
│ 1  1종수술 3/4 │ 1종수술 — 값                                  │
│ 2  2종수술 4/4 │  보험금지급 ⓘ                                  │
│ 3  3종수술 0/4 │    지급률   [  50 ] %                         │
│ …             │    한도     [      ]                          │
│               │  감액기간 (선택 부착)          [부착 해제]      │
│               │    …                                          │
│               │  + 부착 가능: 감액기간문구                       │
└───────────────┴──────────────────────────────────────────────┘
```

- **왼쪽 = 그 층의 노드 목록**(트리 순서대로, 급부 탭은 「세부보장 › 급부」로 묶어서), 노드마다 **완결성 카운트 「입력 n / 부착 m」**(§9.2).
  담보 탭은 노드가 하나(담보 자신)라 왼쪽 열이 없다.
- **오른쪽 = 선택한 노드의 값 폼.** 무조건 노출 구분자는 항상, 선택 부착 구분자는 부착된 것만. 폼 렌더는 P1 렌더러 재사용.
  값 필드는 §1.2 출처 문법 — 직접값 실선, 파생 `ƒ`, const 자물쇠.
- 편집 모드에서만: 값 입력 · 「+ 부착 가능」(선택적 노출 구분자 중 이 레벨 것) · 「부착 해제」(사용처 · 값 행 건수 확인 팝업 — 액션 「부착 해제」).
  부착 · 해제는 파괴적일 수 있어 즉시 실행(개별 확인)이고, 값은 저장 한 번에 묶인다.
- **담보속성(갱신유형 · 추가 · 기본계약 …)은 어느 탭에도 없다.** 이 화면은 담보 마스터다.

### 조작과 상태 전이

| 조작 | 결과 |
|---|---|
| 탭 클릭 | 탭 전환. URL `?tab=` 로 유지. 편집 모드 · 변경분 유지 |
| 편집 | 편집 모드. 네 탭 모두 입력기로 |
| 저장 | 담보명 · 설명 · 노드 이름 · 각 레벨 값을 한 번에 (액션 「담보명 수정」 · 「세부보장명 수정」 · 「급부명 수정」 · 「값 저장」 · 「값 수정」). 거부되면 편집 유지 + 배너, 문제 탭에 표시 |
| ✕ | 변경 있으면 「계속 편집 / 버리기」 |
| 🗑 | 담보 삭제 확인 팝업 |
| 트리 행 클릭 (기본 탭) | 그 노드의 레벨 탭으로 이동 · 선택 |
| + 부착 · 부착 해제 | 즉시 실행 (개별 확인). 값 자리가 생기거나 사라진다 |
| ← 담보 목록 | 조회로. 편집 중 변경 있으면 ✕ 와 같은 확인 |

### 예외 · 빈 상태 · 오류

- 부착된 구분자가 하나도 없는 노드: 「이 층에 묻는 값이 없다」 + 편집 모드면 「+ 부착 가능」 만.
- 최소 구조 위반은 이 화면에서 일어날 수 없다 (구조 조작이 없다).
- 탑재된 담보의 값 수정은 허용 — 마스터 값은 탑재 스냅샷에 소급되지 않는다 ([[06_결정/ADR-0002-탑재-값스냅샷]]). 헤더 사용처 옆에 ⓘ 로 한 줄.

### 인수기준
> [[05_QA/인수기준]] 에 등록 (미등록)

- 담보 상세 어디에도 갱신유형 · 기본계약 · 추가 같은 담보속성이 보이지 않는다.
- 기본 탭에서 담보 › 세부보장 › 급부 세 층이 들여쓰기 · 순번으로 한눈에 보이고, 편집 모드에서도 추가 · 삭제 · 순서 버튼이 없다.
- 세부보장 탭에서 노드를 고르면 오른쪽에 그 노드의 값 폼이 뜨고, 왼쪽 목록에 노드마다 「n / m」이 있다.
- 「← 담보 목록」 이 좌상단, 🗑 이 우상단에 있다. 화면 하단에는 아무 조작도 없다.

## 2. 생성 화면 (`/coverages/new`) — 구조는 여기서 정한다

```
담보명    [                    ]   ⓘ 담보속성(기본계약 · 갱신형 …)은 이름에 넣지 않는다
설명      [                    ]

구조                                         최소: 세부보장 1 · 급부 1
  ├ 1  [세부보장명        ]  ↑ ↓ ✕
  │    ├ 1  [급부명        ]  ↑ ↓ ✕
  │    └ + 급부
  └ + 세부보장
                                                        [생성]
```

- 담보명 · 설명 + **구조 편집기**. 세부보장 추가 · 급부 추가 · 이름 · 순서(↑ ↓) · 삭제(✕). 최소 구조 하한(세부보장 1 · 급부 1)은
  UI 가 강제하고(마지막 하나의 ✕ 비활성 + tooltip) 서버가 다시 검증한다 ([[01_기획/담보_기획]] 트리 편집 규칙).
- 처음 열면 세부보장 1 · 급부 1 이 이름 비운 채 들어 있다. 이름을 안 채우면 담보명을 따른다 (〔D-P2-1〕 기본 이름 = 담보명).
- 형제 이름 중복은 입력 중 즉시 표시, 서버가 거부.
- 「생성」 한 번에 트리 전체가 원자적으로 만들어진다 (〔D-P2-1〕). 생성 → §1 기본 탭.
- 담보명에 담보속성 값이 들어가면 경고 (Q-C).
