# 유저액션 명세

> 상태: 초안 · 최종수정: 2026-09-02

사람이 이 시스템에서 **할 수 있는 일**의 전수 목록. 화면이 아직 없어도 성립하도록
**의도(커맨드) 단위**로 적는다. 작성 원칙의 근거는 [[06_결정/ADR-0018-유저액션명세-작성원칙]].

## 무엇이 여기 있고 무엇이 없나

| 여기 있는 것 | 여기 없는 것 (있어야 할 곳) |
|---|---|
| 사람이 일으키는 행위 하나하나 · 전제 · 결과 · 거부 조건 | **왜 그런 규칙인가** → `01_기획/` |
| 조회 액션 (바꾸는 것 없이 보는 것) | **대표 흐름·기대결과 서사** → `05_QA/시나리오/` |
| 서버가 거부하는 조건 (모드·중복·참조 무결성) | **레이아웃·컴포넌트·픽셀** → `02_UI/화면기획` |
| 근거 문서로의 링크 | **결정의 맥락·버린 대안** → `06_결정/` ADR |

한 문장을 쓰면서 "이건 흐름인데" 싶으면 그건 시나리오 몫이다.
**명세는 목록이지 서사가 아니다.**

## 항목 형식

객체 하나 = `##` 섹션 하나. 섹션마다 표 하나, 액션 하나 = 행 하나.

```markdown
## <객체명>

> 대응 기획: [[01_기획/<주제>_기획]] · 대응 시나리오: [[05_QA/시나리오/<흐름>_시나리오]]

| 액션 | 전제 | 결과 | 거부 | 근거 |
|---|---|---|---|---|
| 구분자 채번 | 코드·표시명·타입 입력 | 카탈로그에 정의 1건 추가 | 코드 중복 시 채번 시점 거부 | [[구분자_기획]] · S2 |

**체크리스트** — 생성 ✓ · 조회 ✓ · 수정 ✓ · 삭제 ✓ · 관계 맺기 ✓ · 관계 끊기 ✓ ·
순서 변경 해당없음(순서 개념 없음) · 상태 전이 ✓ · 복제 해당없음(채번이 곧 신규)

> 진입경로(잠정): 구분자 카탈로그 화면
```

각 열이 담는 것:

- **액션** — 도메인 용어 + 동사. 용어는 [[00_시작/용어사전]] 을 따른다.
- **전제** — 이 액션이 가능하려면 있어야 하는 상태. 모드 제약도 여기.
- **결과** — 저장소에 **무엇이 바뀌나**. 조회 액션이면 `바뀜 없음 — <무엇이 보이나>`.
- **거부** — 서버가 막는 조건. 「화면에서 숨김」은 거부가 아니다 ([[도메인모델]] §5).
- **근거** — `[[기획]]` · `[[ADR]]` · `[[시나리오]]` 위키링크. 없으면 비운다(= 근거 없는 액션 신호).

`진입경로(잠정)` 은 화면기획이 생기면 지운다 — 그때부터 정본은 화면기획이다.

## 완전성 검사

**① 체크리스트 훑기** — 객체마다 아래 9종을 전부 훑고, 해당 없으면 **「해당없음 — 이유」로 명시**한다.
그냥 빠뜨리는 것을 금지한다.

`생성` · `조회` · `수정` · `삭제` · `관계 맺기(부착·참조·탑재)` · `관계 끊기` ·
`순서 변경` · `상태 전이(모드·확정·스냅샷)` · `복제`

**② 시나리오 역방향 대조** — [[05_QA/시나리오]] 13개의 모든 단계가 이 명세의 어떤 액션 하나에
대응해야 한다.
- 대응할 액션이 없는 시나리오 단계 = **명세 누락**
- 대응하는 시나리오도 기획 근거도 없는 액션 = **유령 기능** (지우거나 기획으로 올린다)
