## 임의 결정 (검토 대상)

| ID | 결정 | 이유 | 대안 |
|---|---|---|---|
| D-P6-1 | 그룹 타이틀은 한 상품 안에서 중복 거부 | 타이틀이 책자에 찍히므로 같은 타이틀 두 개는 독자에게 구분 불가 | 중복 허용(순서로만 구별) |
| D-P6-2 | 한 상품담보는 한 그룹에만 소속 | 책자에서 같은 특약이 두 번 나오지 않게 하려면 소속이 하나여야 한다 | 다중 소속 허용 후 출력 시 첫 그룹만 채택 |
| D-P6-3 | 하위 상품담보가 남은 그룹은 삭제 거부 | 삭제로 탑재분이 조용히 미배치가 되는 경로를 막는다 | 삭제 시 하위를 자동 미배치 처리 |
| D-P6-4 | 그룹 간 나열 순서는 유저가 정한다 | 그룹 타이틀에 「1.」 같은 순번이 사람 손으로 들어간다 — 순서도 사람이 잡아야 일치한다 | 타이틀 오름차순 자동 정렬 · 생성 순 고정 |
| D-P6-5 | 미배치 탑재분은 조립을 막지 않고 오류 목록의 「미배치 탑재분」 항목이 되며 책자에서 빠진다 | 부분 조립 원칙과 같은 결 — 막지 않되 「완성본 아님」으로 드러낸다 | 조립 실행 자체를 거부 · 무명 기본 그룹에 자동 수용 |
| D-P6-6 | 기본계약 0건·2건 이상이면 조립 실행 거부 | MVP 는 기본계약 정확히 1개만 다룬다 — 보통약관 문맥이 해소되지 않는다 | 경고만 띄우고 실행 |
| D-P6-7 | 이번 실행이 사용한 문맥 값을 조회할 수 있다 | 오류 원인 추적에 「어떤 값으로 돌았나」가 필요하다 | 두지 않음(값 입력 화면에서 각자 확인) |
| D-P6-8 | 생략 판정 결과를 조별로 조회할 수 있다 | 자동 판정이라 왜 생략/유지됐는지 볼 수단이 없으면 불투명하다 | 두지 않음(결과 문서만으로 판단) |
| D-P6-9 | 문면 없는 담보의 탑재분은 오류가 아니라 「미산출 탑재분」 정보 항목으로 조회 | 문면 없는 담보는 허용된 상태다 — 오류로 올리면 신호가 죽는다 | 오류 목록에 함께 표시 · 아무것도 알리지 않음 |
| D-P6-10 | 오류 목록에 종류·상품담보 필터를 둔다 | 초기 모델링 단계에는 미입력이 수십 건이라 목록이 길다 | 필터 없이 전량 나열 |
| D-P6-11 | 오류 항목에서 원인 입력 자리로 바로 이동할 수 있다 | 「본문 위치로 이동」만으로는 고칠 자리에 도달하지 못한다 | 본문 이동만 제공 |
| D-P6-12 | 오류 목록 순서는 책자 등장 순 고정 | 좌표가 곧 순서라 사람이 정렬을 바꿀 이유가 없다 | 종류별·상품담보별 정렬 허용 |
| D-P6-13 | 미리보기에 문서 목록과 문서 단위 이동을 둔다 | 책자 1권이 특약 10건 이상이라 스크롤만으로 못 다닌다 | 스크롤만 제공(목차는 범위 밖이므로) |
| D-P6-14 | 별표마다 번호를 정한 최초 등장 좌표를 조회할 수 있다 | 상품마다 번호가 달라지므로 「왜 이 번호인가」를 확인할 수단이 필요하다 | 두지 않음(번호만 표시) |
