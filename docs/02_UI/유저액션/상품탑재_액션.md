## 상품담보 = 탑재

> 대응 기획: [[01_기획/상품탑재_기획]] · 대응 시나리오: [[05_QA/시나리오/담보속성탑재_시나리오]] S2·S3·S4

| 액션 | 전제 | 결과 | 거부 | 근거 |
|---|---|---|---|---|
| 담보 탑재 | 상품 존재 · 담보 마스터 존재 · (선택) 담보속성 값 조합 지정 | 상품담보 1건 추가 + 마스터 값이 스냅샷으로 복사(미입력 상태 그대로) + default 상품담보명 생성 | 같은 상품에 (담보, 담보속성 값 조합)이 동일한 상품담보가 이미 있으면 중복 조합 서버 거부 | [[ADR-0002-탑재-값스냅샷]] · [[ADR-0015-담보속성-복원]] · 담보속성탑재 S2 |
| 담보속성 값 조합 수정 | 상품담보 존재 | 조합 갱신 + 규칙 기반 이름 재생성 여부 확인 | 수정 결과가 기존 상품담보와 같은 조합이면 중복 조합 서버 거부 〔D-P5-5〕 | [[ADR-0015-담보속성-복원]] |
| 스냅샷 값 수정 (필드 단위) | 상품담보 존재 · 해당 구분자가 담보 문맥에 부착됨 | 그 필드의 스냅샷 값만 갱신 | 타입·유효값 불일치 | [[ADR-0002-탑재-값스냅샷]] · 담보속성탑재 S4 |
| 상품담보명 수동 변경 | 상품담보 존재 | 이름 갱신 (규칙 생성값과 무관해짐) | 빈 이름 | 담보속성탑재 S3 |
| default 상품담보명 재생성 | 상품담보 존재 | 속성 조합 + 담보명 규칙으로 이름 재생성 (수동 변경분 덮어씀 — 확인 후) | — 〔D-P5-14〕 | 담보속성탑재 S3 |
| 상품담보 조회 | 상품담보 존재 | 바뀜 없음 — 스냅샷 값 · 속성 조합 · 부착 세목 · 이름. 마스터 값 변경은 여기에 반영되지 않는다 | — | [[ADR-0002-탑재-값스냅샷]] · 담보속성탑재 S4 |
| 상품담보 목록 조회 | 상품 존재 | 바뀜 없음 — 같은 담보의 탑재분이 함께 보이는 목록 | — | 담보속성탑재 S2 |
| 담보약관 공용조항 옵션 오버라이드 | 상품담보 존재 · 대상 조항이 옵션 보유 | 상품담보 단위 옵션 선택값 저장 | 정의의 유효 옵션 집합 밖의 값 | [[ADR-0017-옵션-오버라이드]] |
| 탑재 해제 (상품담보 삭제) | 상품담보 존재 | 상품담보 + 스냅샷 값 행 + 세목 부착 + 옵션 오버라이드 연쇄 삭제 | 기본계약으로 지정돼 있으면 거부 (지정 해제 먼저) 〔D-P5-7〕 · 프로덕션에서 그룹 배치·식이 참조 중이면 거부 | [[상품탑재_기획]] · [[조립_기획]] |

**체크리스트** — 생성 ✓(탑재) · 조회 ✓ · 수정 ✓(속성 조합 · 스냅샷 값 · 이름) · 삭제 ✓(탑재 해제) ·
관계 맺기 ✓(담보 마스터 참조 · 담보속성 값 조합 — 세목 부착은 [[#상품세목 = 유효 조합]]) ·
관계 끊기 ✓(속성 제거 · 탑재 해제) ·
순서 변경 해당없음(특약 나열 순서는 그룹핑 + 담보→담보속성→유효값 자동 정렬 — [[조립_기획]] P6 몫) ·
상태 전이 ✓(탑재 자체가 마스터 값 → 스냅샷 전이) ·
복제 해당없음(탑재가 곧 신규 생성이고, 값 복사는 탑재 시점 스냅샷 하나뿐 — 두 번째 복사 시점을
만들지 않는다 [[도메인모델]] §5) 〔D-P5-6〕

> 진입경로(잠정): 상품모델링 → 담보 탑재 화면 · 상품담보 상세 화면
