## 임의 결정 (검토 대상)

| ID | 결정 | 이유 | 대안 |
|---|---|---|---|
| D-P2-1 | 담보 생성 액션이 세부보장 1·급부 1을 함께 만든다 (기본 이름 = 담보명). 세부보장 추가도 급부 1을 함께 만든다 | 최소 구조 하한이 저장소에 한 번도 깨진 채 존재하지 않게 하려면 생성이 원자적이어야 한다 | 빈 담보를 먼저 만들고 저장 시점에 하한 검증 (미완 상태가 저장소에 존재) |
| D-P2-2 | 담보명은 담보 마스터 전역에서 중복 금지 | 「형제 간 이름 중복 금지」의 담보 레벨 형제 = 마스터 전체로 해석 | 중복 허용 (id 로만 구별, 목록에서 사람이 헷갈림) |
| D-P2-3 | 이름 수정은 탑재분이 있어도 프로덕션에서 허용 | 이름은 스냅샷 비대상 뼈대 속성이고 구조 변경이 아니다 | 이름도 구조로 보아 탑재분 있으면 개발 모드 전용 |
| D-P2-4 | 담보 복제 = 트리 · 부착 관계 · 마스터 값 복사, 문면은 복사하지 않음. 이름은 「<원본> 사본」 | 수술비류 담보를 새로 짜는 비용이 크다. 문면은 P4 소유라 여기서 손대지 않는다 | 복제 미제공 / 문면까지 복제 |
| D-P2-5 | 담보 마스터 목록에 순서 데이터를 두지 않는다 (이름순 정렬) | 순서가 데이터인 곳은 트리의 형제 순서뿐. 특약 나열 순서는 조립의 자동 정렬 | 마스터 목록에도 사용자 순서 부여 |
| D-P2-6 | 세부보장·급부 순서 변경도 구조 변경으로 본다 — 탑재분 있으면 프로덕션 거부 | 순서는 데이터이고 이미 탑재된 상품의 문면 수록 순서를 바꾼다 | 값 행에 영향이 없으므로 프로덕션 허용 |
| D-P2-7 | 세부보장 복제는 하위 급부까지, 급부 복제는 자신만 복사. 위치는 원본 바로 뒤 | 1종수술~7종수술처럼 같은 모양의 형제를 늘리는 작업이 실물에 있다 | 복제 미제공 (추가 후 수동 구성) |
| D-P2-8 | 세부보장·급부의 부모 이동(다른 담보/세부보장으로 옮기기)은 제공하지 않는다 | 이동은 값 행의 소속을 옮기는 문제라 스냅샷 규칙이 정해져 있지 않다 | 이동 제공 + 값 행 이관 규칙 신설 |
| D-P2-9 | 무조건 노출 구분자에 대한 부착·해제 요청은 서버가 거부한다 | 부착 관계 없이 전 실체에 뜨는 것이라 관계 데이터가 존재하지 않는다 | 무조건 노출도 부착 행을 만들어 두고 해제만 막기 |
| D-P2-10 | 명시 값 → 미입력으로 되돌리는 「값 비우기」를 액션으로 둔다 | 미입력이 상태라면 그 상태로 돌아가는 경로가 있어야 한다. 없으면 잘못 저장한 값을 지울 방법이 없다 | 되돌리기 미제공 (값은 덮어쓰기만) |
| D-P2-11 | 완결성 조회 범위 = 담보와 그 하위 트리 전체(담보·세부보장·급부 3레벨 부착분) | 파생 집계 범위(부착점의 하위 트리)와 같은 결로 맞춘다 | 담보 레벨 부착분만 보고 |
| D-P2-12 | 세부보장·급부 레벨 값 입력은 담보 레벨과 동일 규칙 — 별도 섹션을 두지 않는다 | 규칙이 레벨과 무관하게 같다. 중복 기재는 관리 지점만 늘린다 | 레벨별 섹션 3개로 분리 |
| D-P2-13 | 담보 삭제는 탑재분·문면 참조가 있으면 프로덕션 거부, 개발 모드는 영향 목록 + 확인 후 허용 | 기획에 삭제 규정이 없다. 구조 변경 가드·부착 해제 가드와 같은 결로 맞춘다 | 탑재분 있으면 모드와 무관하게 영구 거부 |
