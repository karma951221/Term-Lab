# 구분자 기획

> 상태: 합의 · 최종수정: 2026-09-04
> 대응 도메인모델: [[도메인모델]] §2 값의 체계 · 개발 단계: [[개발순서]] P1

## 확정된 전제 (도메인모델에서)

- 타입: string · number · boolean · date · enum · list<enum> · 구조체(중첩 금지).
  ~~list<T>(표 입력)~~ → **2026-09-01 MVP 제외** — 소비처(표 출력)가 동적표와 함께 MVP 밖 ([[범위]])
- 폼 = 구조체 = 구분자 하나. 채번 단위 = 폼. 참조는 경로(`보험금지급.면책여부`)
- 부착 5레벨: 상품 · 세목 · 담보 · 세부보장 · 급부
- const 구분자 (MVP string만) · 파생 구분자 (식 = 데이터, 집계 6종, 부착점 하위 트리)
- **파생식은 실제 계산이 있어야 한다 — 별칭형(`A = B`) 금지** (2026-09-01 확정).
  같은 값에 이름만 얹는 것은 중복 채번의 경위 재생산이다. 값이 필요하면 기존 구분자를
  그대로 참조한다. **채번 시 유사 후보 제시 장치는 MVP 이후 기획** ([[범위]]).
- ~~작명 메타 (값별 prefix/suffix + 조합 순서)~~ → 2026-08-31 담보속성 정의로 이동
  ([[상품탑재_기획]] · ADR-0015)
- 구분자는 문면이 묻는 개념으로 딴다 (불변 규칙)

## 참조 안정성 — 코드 + 표시명 이중 체계 (2026-08-30 확정)

- **모든 식별 단위에 공통 적용**: 구분자 · 구조체 필드 · enum 값.
  **코드(불변)** 가 저장·참조의 정본이고, **표시명(가변)** 은 화면 전용이다.
- 저장되는 식·조건·경로는 코드 기반 (`cov_pay.exempt`). 편집기는 표시명으로 보여주고 변환한다.
- 표시명 변경은 언제든 자유 — 식이 깨지지 않는다. 코드는 채번 후 불변.
- **코드는 시스템 자동 채번 — 유저 입력 불가** (2026-09-01 확정). 중복 코드 사태가
  원천 차단되므로 중복 예외 처리가 없다. 구분자·필드·enum 값 공통.

## 값의 존재 규칙 — null 없음 · 미입력은 상태 (2026-08-30 확정)

- **null 은 타입 체계에 없다.** 조건식·파생식은 null 을 받는 경우가 없다 — 3치 논리 금지.
- **값 자리는 항상 「미입력」 상태로 태어난다.** 기본값 지정 여부와 무관하다.
  저장소의 값 자리는 둘뿐: **명시 입력된 값** 또는 **미입력**.
- **기본값은 선택 항목이고 역할은 폼 프리필뿐이다.** 폼이 열릴 때 미리 채워 보여주는 제안 —
  사람이 보고 저장해야 명시 값이 된다. 기본값이 저장소로 자동 유입되는 경로는 없다
  (아무도 확인 안 한 값으로 약관이 조립되는 것을 구조적으로 차단).
- **미입력은 값이 아니라 상태다.** 식 문법에 등장하지 않는다. 평가·조립·치환이 미입력을
  참조하면 조용히 넘어가지 않고 **명시적 오류 + 좌표 보고** ("상품담보 X 의 A.b 미입력 —
  제3조 분기 평가 불능"). 에디터 사전평가에서 미입력 분기는 톤다운이 아니라 「미결」 표시.
- **완결성 조회** — 조립 전에 "이 상품담보에 미입력 N건"을 보여준다.
  **조회는 실행 기반이다** (2026-09-01 확정 — ADR-0016 「밟은 자리만」과 같은 결):
  담보 마스터 화면은 탑재된 상품담보들의 **실제 타는 분기** 기준으로 담보 레벨 누락을,
  상품 화면은 **보통약관·상품담보별로** 상품 레벨 누락을 보여준다.
- 탑재 스냅샷은 미입력 상태도 그대로 복사한다. 중간 저장은 언제나 허용.

## 변경·삭제 규칙 (2026-08-30 잠정 → 2026-09-04 확정, 역할 가드)

> ~~정식 규칙은 MVP 후 이력·개정 규칙과 함께 기획한다~~ → **2026-09-04 확정** —
> 모드 폐지, 규칙 한 벌 + 관리자 역할 가드 ([[06_결정/ADR-0019-모드폐지-역할권한]]).
> 이력·개정(판본)은 여전히 MVP 이후 ([[2차기획_목록]]).

- **삭제** (관리자) — 값 행 연쇄 삭제. 식·문면이 참조 중이면 참조 목록을 보여주고
  확인 후 삭제 — 깨진 참조는 오류 상태로 표시. 편집자의 삭제 요청은 서버가 역할로 거부.
- **enum 값** — 추가 자유(편집자). 삭제는 위와 같은 규칙(관리자). 표시명 변경은 항상 자유(코드 불변).
- **타입 변경·구조체 필드 삭제** (관리자) — **기존 데이터가 깨진다는 것(소실될 값·깨질 참조
  목록)을 보여주고 확인 후 허용** (2026-09-01 — 전면 금지에서 완화). 타입 변경의 결과는
  해당 구분자의 **저장 값 행 전부 삭제**다 (R11).
- **구조체 필드 추가는 비파괴** (2026-09-01) — 편집자 가능. 기존 저장분에
  새 자리가 미입력으로 나타난다 (기본값 사후 복사 없음 — 트리 노드 추가와 같은 결).
- **사용처 추적(역인덱스)은 P1 포함** — 삭제 가드이자 S3 역방향 조회.
