# 오류 좌표 기획

> 상태: 합의 · 최종수정: 2026-09-06
>
> 2026-09-06 기획 세션에서 합의. 결정의 맥락·버린 대안은 [[ADR-0022-오류좌표-원천과결과]] 에 있다.

## 해결하려는 것

「오류 + 좌표 보고」는 조립 오류 패널([[ADR-0016-조립-부분조립-오류좌표]])·완결성 조회·부착/옵션
재검사 목록·관계정보 뷰에 두루 확정돼 있는데, 좌표의 **표준 형식**이 없었다. 좌표는 사람이 읽는
문자열이면서 화면에서 클릭해 이동하는 키다. 이 문서가 그 둘을 한 규칙으로 정한다.

## 동작 정의

### 1. 키와 표시는 분리한다

- **내부 키는 노드 id 경로**(불변)다. 문서 종류 → 소유 실체 id → (절/블록) → 조 id → 노드 id 경로.
  조·항 번호는 계산값이라 키에 넣지 않는다.
- **표시 문자열은 키를 조립 결과로 렌더한 것**이다. 같은 자리가 상품마다 다른 번호를 가져도 키는 같다.
- 현재 `Coordinate` 타입(id + 선택적 이름)이 이 방향이다. 아래 §2 의 원천/결과 구분과 §3 의
  블록 이름공간을 보태는 것이 설계 갱신 몫이다 → [[03_설계/아키텍처]].

### 2. 좌표는 원천과 결과 자리를 함께 담는다

- **결과 자리**: 오류가 발견된 조립 결과의 위치 (특약 › 상품담보 › 조 › 항 › 노드).
- **원천**: 고치는 곳 — 마스터 문면의 노드, 또는 값 입력 칸.
- 오류 패널의 동작은 둘: **「미리보기에서 보기」**(결과 자리로 스크롤) · **「고치러 가기」**(원천 화면 열기).
- 원천이 둘 이상인 오류(예: 미입력 — 값을 넣어도, 문면에서 참조를 빼도 됨)는 **첫 번째만** 목적지로
  잡는다. 나머지는 보여주지 않는다.

### 3. 오류 종류별 원천

| 오류 종류 | 원천 화면 |
|---|---|
| 미입력 값 참조 | 값 입력 — 상품 레벨이면 상품모델링, 담보 레벨이면 그 상품담보의 값 칸 |
| 미사용 담보속성 참조 | 담보 마스터 문면 편집기, 그 조건식 노드 |
| 깨진 참조(구분자·필드·enum·공용조항·조·별표) | 그 참조가 있는 문면 편집기(담보 마스터 / 보통약관 / 공용조항 정의), 그 노드 |
| 대상 조가 분기로 사라짐 | 참조 슬롯이 있는 문면 편집기, 그 노드 |
| 옵션 미선택 · 유효 옵션 밖 | 옵션을 고르는 곳 — 문면의 참조 노드, 오버라이드면 상품모델링의 그 항목 |
| 기본계약 미지정 | 상품모델링 기본계약 섹션 |
| 조연결 없는 기본계약 조 (warning, [[준용생략_기획]]) | 담보 마스터 문면 편집기, 그 조 |

### 4. 표시 문자열 규칙

「아는 만큼만」 왼쪽부터 채우는 경로. 구분자 `›`, 조는 `제N조(조 명)`, 항은 `①②…`, 노드는 `종류:상세`.
절·보장조항 블록은 조 앞에 한 단계로 들어간다 (0·2+ 모드 — 블록 안 조 번호가 재시작하므로 필수).

```
결과 자리:  특약 › 일반상해사망 추가 › 제3조(보험금을 지급하지 않는 사유) › ② › 슬롯:보험금지급.지급률
0/2+ 모드:  보통약관 › 제2절 2. 일반상해사망 › 제1조(보험금의 지급사유) › ①
원천:       담보 마스터 › 일반상해사망 › 「보험금을 지급하지 않는 사유」 › 2번째 항 › 조건식
값 원천:    상품모델링 › 알파Plus › 일반상해사망 추가 › 보험금지급.지급률
```

- **원천 좌표에는 번호가 없다** — 조 명 + 「n번째」로 쓴다. 마지막 조립의 번호를 빌리지 않는다.
- severity(error / warning)는 좌표가 아니라 issue 의 속성이다. 패널이 구분해 표시한다.

## 규칙과 경계

- 이 규칙을 쓰는 곳: 조립 오류 패널 · 완결성 조회 · 공용조항 부착/옵션 재검사 목록 · 관계정보 뷰 ·
  파괴적 액션의 Impact(깨질 참조 목록). 전부 같은 렌더러를 쓴다.
- 관계정보 뷰의 「좌표 클릭 이동」은 §2 의 「고치러 가기」와 같은 이동이다 (원천으로).
