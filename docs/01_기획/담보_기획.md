# 담보 기획

> (2026-08-31 정합 수정 — 2026-08-30 결정이 커밋 기록에만 있고 문서에 빠져 있어 반영)
> 대응 도메인모델: [[도메인모델]] §1 담보 트리 · 개발 단계: [[개발순서]] P2

## 확정된 전제 (도메인모델에서)

- 담보 > 세부보장 > 급부 2단 트리. 구조는 마스터 소유, 전 상품 동일.
- 단순 담보(각 1개)도 같은 3층의 최소 사례로 표현.
- 문면(담보약관)은 담보가 1벌 소유. 탑재분마다 문서 파생.
- 탑재된 상품이 있는 담보의 구조 변경: 프로덕션 서버 거부, 개발 모드 허용
  (추가 노드 빈 값, 삭제 노드 값 행 연쇄 삭제).
- 값 입력 폼은 P1 렌더러 재사용.

## 구분자 부착의 범위 — 노출여부 (2026-08-30 확정, 기존 시스템 차용 후 단순화)

구분자 정의가 **노출여부**를 갖는다. **모든 부착 레벨(상품·세목·담보·세부보장·급부)에 동일 적용.**
MVP 는 **체크박스 하나 — 「무조건 노출」**:

| 무조건 노출 | 동작 |
|---|---|
| ☑ 체크 | 그 레벨 모든 실체의 모델링 화면에 항상 나타난다 (예: 갱신유형 같은 공통 축) |
| ☐ 해제 (= 선택적 노출) | 기본으로는 안 나타나고, 모델링 화면에서 **+ 버튼으로 유저가 찾아 추가**한 실체에만 붙는다 (예: 담보 전용 값) |

> 기존 시스템의 3번째 값 「노출하지 않음」(화면·+버튼 모두 비노출)은 **용도 불명으로 MVP 미사용**
> (2026-08-30 결정). 파생·const 는 입력이 없어 자연히 비노출이다. 필요가 확인되면 그때 연다.

- 폼 = 구조체 전제와 결합하면: 무조건 노출 = 그 폼이 모든 담보에 자동으로 뜸,
  선택적 노출 = 담보마다 폼을 골라 붙임. 선택적 부착 관계(담보 ↔ 구분자)가 데이터로 남는다.
- **완결성 조회(미입력 검사)는 부착된 것만 대상** — 수술비 전용 값이 일반상해사망의
  미입력 경고로 뜨는 오염이 구조적으로 없다.

## 이름의 정체 — 뼈대 속성 (2026-08-30 확정)

담보명·세부보장명·급부명은 구분자 값이 아니라 **뼈대 속성**이다 ([[도메인모델]] §0).

- 스냅샷 비대상 — 탑재 시 복사되는 것은 구분자 값뿐이고, 이름은 구조와 함께 마스터가 소유한다.
  (상품 쪽 이름은 별개 — 상품담보명은 작명 규칙으로 생성, [[도메인모델]] §1.)
- 식·반복문은 **내장 경로**로 접근한다 (`세부보장.세부보장명`) — 구분자 참조와 문법은 같되
  출처는 뼈대다.

## 트리 편집 규칙 (2026-08-30 확정)

- **최소 구조 강제** — 담보는 세부보장 1개 이상, 세부보장은 급부 1개 이상.
  단순 담보 = 각 1개인 최소 사례 ([[도메인모델]] §1).
- **형제 간 이름 중복 금지.**
- **순서는 데이터다** — 트리의 형제 순서가 곧 문면 수록 순서·반복 순회 순서다.
