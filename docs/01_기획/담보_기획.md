# 담보 기획

> 상태: 초안 · 최종수정: 2026-08-30
> 대응 도메인모델: [[도메인모델]] §1 담보 트리 · 개발 단계: [[개발순서]] P2

## 확정된 전제 (도메인모델에서)

- 담보 > 세부보장 > 급부 2단 트리. 구조는 마스터 소유, 전 상품 동일.
- 단순 담보(각 1개)도 같은 3층의 최소 사례로 표현.
- 문면(담보약관)은 담보가 1벌 소유. 탑재분마다 문서 파생.
- 탑재된 상품이 있는 담보의 구조 변경: 프로덕션 서버 거부, 개발 모드 허용
  (추가 노드 빈 값, 삭제 노드 값 행 연쇄 삭제).
- 값 입력 폼은 P1 렌더러 재사용.

## 열어 둔 문제

- [ ] 구분자 부착의 범위 — 레벨 전체 공통인가, 담보별 선택인가
- [ ] 담보명·세부보장명·급부명의 정체 — 뼈대 속성인가 구분자 값인가
  (반복문이 `세부보장.세부보장명`을 찍는다 — 식에서 접근 가능해야 함)
- [ ] 트리 편집 규칙 — 순서·추가·삭제·이름 규칙
- [ ] 담보 마스터 값 입력 화면의 구성
