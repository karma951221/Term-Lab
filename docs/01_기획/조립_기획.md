# 조립 기획

> 상태: 합의 · 최종수정: 2026-08-31
> 대응 도메인모델: [[도메인모델]] §4 조립 · 개발 단계: [[개발순서]] P6

## 해결하려는 것

상품의 실제 값으로 문서트리를 만들어 **책자 화면 미리보기**까지 — 관통 1의 종점.
조건 해소·생략 판정·번호 계산·참조 슬롯 해소가 여기서 실행되고,
**오류를 어떻게 만나고 보여주는가**가 이 기획의 본체다.

## 확정된 전제 (도메인모델·기존 기획에서)

- 책자 순서: 보통약관 → 특별약관들 → 별표들. 표지·목차는 범위 밖. 종점은 화면 미리보기 (`.docx` 밖).
- 조건 해소 문맥 = 상품 구분자 값 + 상품담보의 스냅샷 값 + 담보속성.
  보통약관 문맥의 담보 레벨 참조는 기본계약으로 해소 ([[ADR-0011-보통약관문맥-기본계약]]).
- 생략하기는 리터럴 비교 자동 판정 ([[ADR-0014-생략-자동판정]]) — 조건 해소 후 실행.
- 번호(조·항·별표)는 계산값 ([[ADR-0012-문면-노드트리-구조편집기]] · [[문면_기획]]).
- **조립은 매번 재계산한다** — 결과 저장·시점 스냅샷 회귀 비교는 MVP 밖 ([[범위]]).

## 조립 = 구체 문맥의 실행 — 오류 처리 (2026-08-31 확정 → [[ADR-0016-조립-부분조립-오류좌표]])

- 조립은 특정 상품의 **실제 값**을 넣고 문서트리를 만드는 **실행**이다.
  오류는 **실행이 실제로 밟은 자리에서만** 탐지한다 — 조건에 걸려 밟지 않은 분기
  안쪽은 평가하지 않으므로, 거기 있는 미입력·깨질 수 있는 참조는 이 상품의 오류가 아니다.
  **가능한 분기 조합 전체를 정적으로 검사하지 않는다** (사용자 부담 — 만들지 않는다).
- 오류 종류: 슬롯·조건식의 **미입력 값** 참조 · **미사용 담보속성** 참조 ·
  대상이 분기로 사라진 **조 참조** 등.
- **부분 조립** — 오류를 만나도 중단하지 않고 그 자리에 **오류 마커 노드**를 심고 계속 간다.
- 결과 = 미리보기(본문 마커 표시) + **오류 목록 패널** — 항목마다 좌표(상품담보 → 조 → 위치)와
  원인, 클릭 시 해당 위치로 이동. 오류가 1건이라도 있으면 **「완성본 아님」** 표시.

## 특약 배치 = 그룹핑 (2026-08-31 확정)

- **특약들 사이의 전역 순서는 중요하지 않다 — 배치는 그룹핑이다.**
- 유저가 상품모델링에서 **그룹**을 만든다: 그룹 타이틀(예: 「1. 상해 관련 특별약관」)이
  책자에 찍히고, 하위에 상품담보들을 배치한다.
- **같은 담보의 탑재분들은 뭉친다.**
- **한 그룹 = 한 보통약관 템플릿** — 조연결이 다른 보통약관 템플릿을 가리키는 담보가
  한 그룹에 공존할 수 없다 (검증 규칙). MVP 는 단일 템플릿이라 자동 충족되지만
  규칙은 모델에 둔다.

## 별표 (2026-08-31 확정)

- 그 책자에서 **참조된 별표만** 수집한다 (superset 마스터 + 불변 코드 — [[문면_기획]]).
- 나열 순서 = **본문 등장 순** (조립된 책자를 앞에서부터 읽을 때 별표 참조가 처음
  등장하는 순서). 번호는 그 순서로 계산 — 유저 정렬은 두지 않는다.

## MVP 이후 — 다중 보통약관 (2026-08-31 유예 · 개발 필요 기록)

현행 시스템의 실례 (실제 용어로 기록):

- **배상책임 담보는 별도의 배상책임 보통약관 템플릿을 쓴다** (일반 담보는 일반 보통약관 템플릿).
- 한 상품에 일반 담보 + 배상책임 담보가 탑재되고 **기본계약이 일반 담보**인 경우:
  - 책자의 보통약관은 **일반 보통약관 템플릿** 기준으로 출력한다.
  - 특별약관부에 **「배상책임 관련 특별약관」 그룹**을 만들고, 내부를 절로 가른다 —
    **제1절 일반조항** = 배상책임 보통약관 템플릿 문서 · **제2절 보장조항** = 배상책임 특약들.
  - 배상책임 담보의 조연결은 배상책임 보통약관을 참조한다.
  - **배상책임 보통약관은 일반 보통약관과 다른 내용만 적고, 같은 내용은 일반 보통약관을
    준용한다** — 보통약관 템플릿 **간** 조별 조연결(준용 관계)이 있어야 성립한다.
- 여기에 **기본계약이 여러 개인 주계약**이면 보통약관 자체가 제1절 일반조항 /
  제2절 보장조항으로 나뉜다 — 복잡도가 한 단 더 오른다.
- **MVP 는 기본계약 1개 + 단일 보통약관 템플릿만 다룬다** ([[범위]]).
  다중 보통약관은 템플릿 간 조연결·일반조항 절 출력과 함께 MVP 이후 기획한다.
