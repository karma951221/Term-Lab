# 2차 세부기획 목록

> 상태: 진행판 · 최종수정: 2026-09-05
>
> 1차 기획(P1~P6 합의, 2026-09-01)에서 **부족한 지점**을 feature 별로 모은 작업판.
> 항목이 추가 기획으로 해소되면 체크하고 결과 문서(기획 절·ADR)를 링크한다.

## 우선 — 문면·조립의 빈 곳

- [ ] **준용·생략 (보통약관 ↔ 특별약관)** ← 2026-09-01 유저 지목, 최우선
  - 부족: 조연결로 확정된 것은 「대응 보통약관 조 선택」과 「(조 명 제외) 완전 동일 시 생략」
    (ADR-0014)뿐이다. 실물의 준용은 그 이상이다 — 내용이 **다른데도** 보통약관 조를 따르며
    일부만 예외로 두는 관계, 「이 특별약관에서 정하지 않은 사항은 보통약관을 따릅니다」류
    준용 문구, 기존 시스템 3종(생략·덮어쓰기·준용/생략 예외처리)이 담당하던 동작의 대체 규칙.
  - 추가 기획: **준용생략_기획** 문서 신설 — ① 조연결 관계의 유형 분류(생략/준용/예외부 준용 등
    — 기존 3종을 그대로 따르지 않되 대체 규칙 확정) ② 각 유형의 조립 처리(문서에 무엇이
    찍히나) ③ 준용 문구 자동 생성 여부 ④ 보통약관 조에 정의한다는 「조합 옵션」의 구체화
    ⑤ 기본계약 문면이 보통약관 조가 되는 경로([[도메인모델]] §7 미결) ⑥ 편집 화면의 표시.
- [ ] **오류 좌표 체계**
  - 부족: 「오류 + 좌표 보고」가 도처에 확정돼 있으나 좌표의 **표준 형식**이 없다.
  - 추가 기획: 문서 종류 → 실체(상품담보 등) → 조 → 노드 경로의 표기 규칙 하나로 —
    조립 오류 패널·완결성 조회·부착/옵션 재검사 목록·관계정보 뷰가 전부 공유.
- [ ] **조·별표 참조 슬롯의 렌더 표기** — 실물 조사 대기 ([[문면_기획]] 열어 둔 문제).
  로컬 실물 자료(`docs/_자료/`)로 「제3조(보험금의 지급사유)」·「【별표13(…)】」 형식 확정.
- [ ] **슬롯 값 포맷 규칙** — number → 「2.50%」·「1,000만원」 표시를 누가 정하나
  ([[도메인모델]] §7 미결 — P4 구현 중 확정 예정이나 규칙 방향은 미리).

## 값의 세계

- [x] **식 언어 문법 상세** → 2026-09-04 구현과 함께 확정 [[03_설계/식언어]] (편집기 입력 방식은 미결)
  - 부족: 통일(ADR-0013)과 재료(경로·비교·and/or·집계 6종·담보속성 exist/=/≠)만 확정.
  - 추가 기획: 문법 확정(연산자·리터럴·경로 표기·우선순위), 타입 규칙(조건 자리 = boolean),
    식 편집기의 입력 방식(자유 타이핑 + 자동완성 vs 구조 빌더).
- [ ] **작명 규칙 문법**
  - 부족: 「담보속성별 담보명 규칙(prefix/suffix)·조합 적용 순서」(ADR-0015)의 구체 문법 없음.
  - 추가 기획: 규칙 표기(값별 접두/접미·결합 순서·공백 규칙), 미사용 속성 처리,
    예제 검증(갱신형 + 추가 → 「갱신형 일반상해사망보장 추가」).
- [ ] **세목 세부**
  - 부족: 축 모델·명시 등록은 확정이나, 세목유형 구조체 5종(납입면제·무저해지·계약전환·
    영위업종적용·납입형태)의 실제 필드 정의가 없다. 축·번호 편집 동작, 유효 조합 등록 흐름,
    담보 적용범위(상품담보별 세목 부착)의 조작도 미정.
  - 추가 기획: 유형 5종 필드 정의(실물 근거), 세목 등록·조합 등록의 동작 정의.
