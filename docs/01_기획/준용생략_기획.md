# 준용·생략 기획

> 상태: 합의 · 최종수정: 2026-09-06
>
> 2026-09-06 기획 세션에서 합의. 결정의 맥락·버린 대안은 [[ADR-0020-준용-항단위-자동판정]] ·
> [[ADR-0021-기본계약수-보통약관구조]] 에 있다.

## 해결하려는 것

보통약관에 이미 있는 내용을 담보마다 다시 찍지 않는다. 1차 기획은 「(조 명 제외) 완전 동일 시
생략」([[ADR-0014-생략-자동판정]])까지만 정했고, 실물의 준용은 그 이상이다 —
① 보통약관 조가 담보 조를 포함하는 경우 ② 담보 조가 보통약관 조를 포함하는 경우 ③ 기본계약
담보의 내용이 보통약관 조 자체가 되는 경로 ④ 기본계약이 없거나 여럿인 상품의 보통약관 구조.
이 문서는 그 전부를 **자동 판정 하나 + 기본계약 수에 따른 구조 규칙**으로 닫는다.

기존 시스템 3종 옵션(생략·덮어쓰기·준용/생략 예외처리)은 그대로 따르지 않는다 (아래 §대응표).

## 동작 정의

### 1. 항 단위 자동 판정 (모든 모드 공통)

조연결된 두 조(담보 조 ↔ 보통약관 조)를 조립 시점에 비교한다.

- **비교 단위는 항**이다. 항 하나의 「조건 해소가 끝난 텍스트」를 리터럴 비교한다 — 같은 공용조항을
  썼느냐, 조건식이 같으냐가 아니라 **결과 텍스트가 완전히 같으냐**다 (ADR-0014 기준 그대로:
  띄어쓰기 하나 달라도 다르다).
- **관계는 사람이 선언하지 않는다.** 조연결만 해두면 조립이 판정한다.
- 판정 결과는 세 갈래:

| 관계 | 조건 | 출력 |
|---|---|---|
| **생략** | 담보 조의 모든 항 = 보통약관 조의 모든 항 | 담보 조를 찍지 않는다 |
| **준용** | 보통약관 조의 모든 항이 담보 조 안에 동일하게 있고, 담보 조에 항이 더 있다 | 제1항 = 준용 문장, 그 뒤에 **보통약관에 없는 항만** 원래 순서대로 |
| **통째** | 그 외 (보통약관 항 중 담보 조에 없는 것이 하나라도 있음) | 담보 조를 그대로 찍는다 |

- 준용 문장 템플릿: 「이 특별약관의 **[담보 조 명]**은/는 보통약관 제N조(**[보통약관 조 명]**)를 준용합니다.」
  조사(은/는)는 받침으로 자동 선택. 조 번호 N 은 조립 시 계산값이다.
- 판정은 **탑재분별**이다 — 같은 담보라도 값이 다르면 결과가 갈린다 (ADR-0014).

### 2. 「비교 제외」 옵션 — 보통약관 조 ⊇ 담보 조

보통약관 조가 담보 조의 내용에 **더해** 무언가를 더 갖고 있어도, 문맥상 보통약관 조가 담보 조를
포함해 준용해도 되는 경우가 있다 (기존 시스템의 「준용/생략 예외처리」).

- 보통약관 마스터의 조 안에 삽입된 **block 공용조항 참조 노드**에 「비교 제외」 옵션을 둔다.
- 켜져 있으면 판정 시 보통약관 조의 항 목록에서 **그 항을 뺀 나머지**를 기준으로 §1 의 세 갈래를
  적용한다. 그 결과 담보 조와 완전 동일이면 생략된다.
- **block 참조에만** 둔다. inline 참조는 대상이 아니다 (항 텍스트 일부를 오려내는 규칙을 만들지
  않는다).
- 이것이 「보통약관 조에 정의하는 옵션」의 **전부**다. 적용 단위는 조 전체가 아니라 조 안의 참조
  노드다 — 도메인모델의 「적용 단위 = 조 전체」는 2026-09-06 정정.

### 3. 기본계약 수에 따른 보통약관 구조 (0 / 1 / 2+)

상품모델링은 담보를 **「기본계약」 섹션과 「특별약관」 섹션**에 나눠 추가한다. 기본계약 섹션의
상품담보 수가 모드를 정하며, 보통약관 마스터는 **평평한 조 목록**일 뿐 절 구조를 갖지 않는다 —
절은 조립이 만든다.

| 기본계약 수 | 상품 종류 | 보통약관 출력 | 특별약관 출력 | 판정 기준 |
|---|---|---|---|---|
| **0** | 독립특약 | 제1절 일반조항 = 마스터 조 목록 · 제2절 보장조항 = **모든 담보** 블록 | 없음 | 블록 조 ↔ 일반조항 조 |
| **1** | 주계약 | 절 분리 없음. 마스터 조 목록 그대로, **조연결된 조는 기본계약 조로 대치** | 특별약관 섹션 담보 | 특약 조 ↔ 보통약관 조(대치 후) |
| **2+** | 주계약 | 제1절 일반조항 = 마스터 조 목록 · 제2절 보장조항 = **기본계약** 블록 | 특별약관 섹션 담보 | 블록 조·특약 조 ↔ 일반조항 조 |

- **독립특약**은 기본계약이 없어 단독 가입이 불가한 상품이다. 주계약 상품에 부가돼 가입된다.
  담보별 공통 내용은 제1절 일반조항(마스터)에, 담보별 상이 내용은 제2절 보장조항의 블록에 찍힌다.
- **보장조항 블록**: 담보(상품담보)마다 하나. 번호 `1.` `2.` … + 상품담보명이 제목이고, 블록 안에서
  조 번호는 1부터 다시 시작한다. 블록 순서는 특약 그룹 안 정렬과 같은 규칙(담보 → 담보속성 종류
  → 유효값)이다. 블록 안 조는 §1 판정을 그대로 받는다 — 일반조항과 동일한 조는 생략되고,
  포함하면 준용 문장이 찍힌다. 실물 근거: 내Mom같은어린이보험 2604 보통약관 제2절 1-1·1-2
  (각각 제1조~제4조, 「지급하지 않는 사유」는 제1절 제5조 하나만 존재).
- **1개 모드의 대치**: 기본계약 담보 조가 조연결된 보통약관 조는 **항상** 그 기본계약 조의 내용으로
  찍힌다. 마스터의 그 조는 제목만 있는 빈 조여도 된다. 토글·옵션은 없다 — 조연결 자체가 대치다.
  조연결 없는 기본계약 조는 어디에도 찍히지 않고 **경고**로 보고한다. 실물 근거: 알파Plus 보통약관
  제3조(지급사유)·제4조(세부규정)가 일반조항 사이에 그대로 있다.
- **0·2+ 모드에서는 대치가 없다.** 조연결은 판정용이다. 1개 모드에서만 대치가 동작하므로 같은
  마스터·같은 담보가 상품에 따라 다르게 조립될 수 있다 — 마스터는 그 모드에 맞게 작성한다
  (예: 0/2+ 용 마스터의 제3조는 「이 계약의 보험금의 지급사유는 제2절 보장조항에서 정합니다」).
- 기본계약 담보는 **특약 벌로 따로 찍히지 않는다** (1개: 대치로, 0·2+: 블록으로만 나온다).

### 4. 준용규정 조는 조립이 붙인다

블록·특약 끝의 준용규정(「이 특별약관에서 정하지 않은 사항은 보통약관을 따릅니다」 / 「이 보장조항에서
정하지 않은 사항은 제1절 일반조항을 따릅니다」)은 출력 위치(특약 / 보장조항 블록)를 타므로
**담보 문면에 쓰지 않고 조립이 모드에 맞는 문장을 자동 생성**한다. 문면 작성자는 모드를 신경
쓰지 않는다. → 문장 상세·항 구성은 **MVP 이후** 기획 ([[2차기획_목록]]).

### 5. 오류와 경고

- issues 에 **severity 두 단계(error / warning)** 를 둔다. warning 은 `complete` 를 깨지 않는다.
- warning: 1개 모드에서 조연결 없는 기본계약 조.
- error: 기존 ADR-0016 의 오류 전부. 모드-마스터 불일치 오류는 **없다** — 마스터가 절 구조를
  갖지 않으므로 어긋날 것이 없다.

## 기존 시스템 3종과의 대응

| 기존 옵션 | 새 시스템 | 옵션이 남나 |
|---|---|---|
| 생략 | §1 항 단위 자동 판정 (생략 / 준용) | 없음 — 자동 |
| 덮어쓰기 | §3 1개 모드의 조연결 = 대치 | 없음 — 조연결 자체 |
| 준용/생략 예외처리 | §2 block 공용조항 참조의 「비교 제외」 | 하나 — 조가 아니라 참조 노드에 |

기존 3종이 하던 동작 중 위 표로 덮이지 않는 것은 없다 (2026-09-06 확인).

## 규칙과 경계

- 조립 파이프라인의 「생략 판정」 단계가 「항 단위 판정 + 준용 문장 생성 + 모드별 배치」로 커진다
  → [[03_설계/아키텍처]] 갱신 대상.
- 조 명은 비교에서 제외한다 (ADR-0014 유지). 항이 없는 조(문장 하나)는 항 1개로 본다.
- **MVP 구현 범위는 기본계약 1개 모드**다 ([[범위]]). 0·2+ 모드는 기획은 확정, 구현은 MVP 이후 —
  단 저장 모델·파이프라인은 단수로 하드코딩하지 않는다 (범위 §구현 제약 그대로).
- 다중 보통약관(배상책임 템플릿)은 여전히 MVP 이후 ([[조립_기획]]). 그때 「그룹 안 제1절/제2절」은
  이 문서의 0 모드 구조를 재사용한다.

## 화면

- 조연결 UI 는 기존 최소형(담보 조 → 보통약관 조 선택) 그대로. 관계 유형 선택은 **없다**.
- 보통약관 편집기: block 공용조항 참조 노드에 「비교 제외」 체크 하나.
- 상품모델링: 담보 추가가 「기본계약 / 특별약관」 두 섹션으로 갈린다 → [[상품탑재_기획]] · [[02_UI]].
- 조립 미리보기: warning 을 error 와 구분해 표시.

## 열어 둔 문제

- 준용규정 조 자동 생성의 문장·항 구성 상세 (MVP 이후).
- 준용 문장의 「보통약관 제N조」 표기가 0·2+ 모드에서 「제1절 제N조」가 되는지 — 실물 확인 후.
- 항 순서가 다르지만 집합이 같은 경우의 판정 (현재 규칙: 순서 무관하게 항 단위 매칭. 실물 반례 나오면 재검토).
