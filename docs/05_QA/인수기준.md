# 인수기준

> 상태: 초안 · 최종수정: 2026-09-01

기능이 "됐다"고 말할 수 있는 조건. 기획 문서마다 대응한다.
상세 흐름은 [[05_QA/시나리오]] 의 각 시나리오가 갖는다.

## 프로젝트 인수 (문제정의 S1~S4)

| 기준 | 내용 | 검증 방법 |
|---|---|---|
| S1 | 구분자 추가에 코드 배포가 필요 없다 — 유효값이 데이터에서 나온다 | 새 구분자 채번 → 배포 없이 폼·식에서 사용 |
| S2 | 중복 채번이 채번 시점에 막힌다 | [[시나리오/체증체감납_인수시나리오]] |
| S3 | 값 하나를 짚으면 결정 출처가 하나로 나온다 | 관계정보 뷰 역방향 조회 |
| S4 | 체증·체감납 사례 통과 — 「보험료 가벼운 납입형」이 별도 채번되지 않는다 | [[시나리오/체증체감납_인수시나리오]] |

## 기능 인수기준

| 기능 | 인수기준 | 검증 방법 | 상태 |
|---|---|---|---|
| 구분자 카탈로그 (P1) | 코드 불변·표시명 가변. 표시명 변경 후에도 저장된 식·참조가 깨지지 않는다 | [[시나리오/구분자정의_시나리오]] | 초안 |
| 값의 존재 규칙 (P1) | null 없음. 기본값은 프리필뿐 — 저장 전엔 미입력. 미입력 참조 평가는 오류+좌표 | [[시나리오/폼입력_시나리오]] | 초안 |
| 폼 렌더러 (P1) | 구조체 필드 메타만으로 폼이 그려진다 (7개 타입 전부) — 폼별 코드 없음 | [[시나리오/폼입력_시나리오]] | 초안 |
| 사용처 추적 (P1) | 삭제 시도 시 참조 목록 제시. 프로덕션에서 사용 중 삭제는 서버 거부 | [[시나리오/구분자정의_시나리오]] | 초안 |
| 모드 (P1) | 파괴적 변경은 개발 모드에서만 — 화면 숨김이 아니라 서버가 거부 | [[시나리오/모드전환_시나리오]] | 초안 |
| 담보 트리 (P2) | 최소 구조 강제(세부보장 1·급부 1)·형제 이름 중복 금지·순서가 데이터 | [[시나리오/담보트리_시나리오]] | 초안 |
| 노출여부 (P2) | 무조건 노출 = 전 실체 자동 표시, 선택적 = +버튼 부착. 완결성 조회는 부착분만 | [[시나리오/담보값입력_시나리오]] | 초안 |
| 공용조항 (P3) | 참조 전파·옵션 수동 선택·배치 순서 보존. 참조 추가 순간 부착 검사, 수정 시 사용처 재검사 | [[시나리오/공용조항_시나리오]] | 초안 |
| 문면 편집 (P4) | 구조 편집기에서 조·항·호·목 + 인라인/블록 조건 + 슬롯. 번호는 계산값 — 조 추가 시 이후 번호·참조가 함께 민다 | [[시나리오/문면작성_시나리오]] | 초안 |
| 사전평가 (P4) | 담보 마스터 값 기준 톤다운, 미입력·상품 레벨·담보속성 조건은 「미결」, 전체 뷰 토글 | [[시나리오/사전평가_시나리오]] | 초안 |
| 세목 (P5) | 유효 조합은 명시 등록만 — 등록 안 된 조합은 존재하지 않는다 | [[시나리오/세목구성_시나리오]] | 초안 |
| 담보속성·탑재 (P5) | 상품담보 = 담보 × 속성 조합, 중복 조합 서버 거부. 스냅샷 후 마스터 변경 무영향 | [[시나리오/담보속성탑재_시나리오]] | 초안 |
| 조립 (P6) | 실행이 밟은 자리만 오류 탐지. 부분 조립 + 마커 + 좌표 패널, 오류 있으면 「완성본 아님」 | [[시나리오/조립오류_시나리오]] | 초안 |
| 그룹핑·별표 (P6) | 그룹 타이틀 출력·같은 담보 탑재분 뭉침. 별표는 참조된 것만, 등장 순 번호 | [[시나리오/그룹핑별표_시나리오]] | 초안 |
| ★ 관통 1 (P6) | 보통약관 + 일반상해사망보장 + 「추가」 생성 결과가 원문과 일치 (눈 검증) | 조립 미리보기 ↔ 원문 대조 | 초안 |
