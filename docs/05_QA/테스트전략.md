| 층 | 도구 | 무엇을 | 방식 |

| `src/app/**` | `next build` + Playwright 소수 | 라우트 존재·서버 액션 입력 파싱·로그인 → 미리보기 스모크 | 화면이 깨졌나만 |

테스트 설명은 **시나리오 문장 그대로**(한국어) — [[05_QA/시나리오]] 역방향 대조가 곧 테스트 목록이다.

## 자동화 범위

- `npm test` (vitest) · `npm run typecheck` · `npm run lint` — 전부 녹색이 커밋 조건.
- 관통 1 은 `src/domain/assembly/assembly.test.ts` 스냅샷이 고정한다: 보통약관 + 특약 2벌(본문 동일·제목만 다름) ·
  조연결 생략 · 별표 번호 1 · issues 0 · complete true. 조립 로직을 바꾸면 스냅샷 diff 로 영향이 드러난다.
- 시드(`npm run db:seed`)는 마지막에 `assembly.preview` 로 complete 를 확인한다 — 시드 데이터가 곧 회귀 픽스처.

## 수동 확인이 필요한 것

- **원문 대조(눈 검증)** — 인수기준 「★ 관통 1」. 실물 텍스트(`docs/_자료/`)는 리포 밖이라 자동화하지 않는다 (ADR-0009).
- 화면 조작 감각(구조 편집기·톤다운 표시) — 화면기획([[02_UI]]) 확정 후 Playwright 로 격상.
- 값 포맷(「2.50%」·「1,000만원」)·조/별표 참조 표기 — 실물 조사 후 규칙 확정 전까지 임시 규칙.
