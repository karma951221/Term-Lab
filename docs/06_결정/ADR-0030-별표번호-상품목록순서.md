# ADR-0030 — 별표 번호는 상품 별표 목록의 순서다

> 상태: 채택 · 날짜: 2026-09-07

## 맥락

문면_기획·조립_기획은 「책자에서 참조된 별표만 모아 본문 등장 순으로 번호」를 정했다.
실물(알파Plus)은 보통약관 본문에서 별표2(장해분류표)가 별표1(적립이율 계산)보다 먼저 등장하고,
특약은 별표13·14·15·21 처럼 띄어 있는 번호를 쓴다. 즉 실물 번호는 **상품 별표 목록의 고정 순서**다.

## 결정

- 상품이 **순서 있는 별표 목록**을 갖는다. 별표 번호 = 그 목록의 위치.
- 본문이 참조한 별표가 목록에 없으면 조립 오류 + 좌표. 목록에 있으나 참조되지 않은 별표는 번호만 차지한다.
- 「등장 순 자동 계산」은 폐기한다.

## 이유

실물 번호는 참조 순서가 아니라 별표 책자의 편집 순서다. 자동 계산으로는 실물을 재현할 수 없다.

## 버린 대안

- 등장 순 유지 + 대조에서 번호 무시 — 실물과 다른 약관을 내면서 「같다」고 판정하는 셈. 기각.
- 별표 마스터에 전역 고정 번호 — 상품(책자)마다 별표 구성이 다르므로 전역 번호는 성립하지 않는다.

## 결과와 감수하는 비용

- 상품모델링에 별표 목록 편집 단계가 하나 는다. 별표를 참조하는 담보를 탑재하면 목록에도 넣어야 한다 — 빠지면 조립 오류로 드러난다.
- 별표 내용 출력은 여전히 범위 밖.
