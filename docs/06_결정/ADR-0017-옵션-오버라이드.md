# ADR-0017 — 공용조항 옵션: 저장 시점 검사 + 상품모델링 오버라이드

> 상태: 채택 · 날짜: 2026-09-01

## 맥락

공용조항 옵션은 수동 선택이고 사용처(담보약관·보통약관 마스터)가 고른다
([[ADR-0008-공용조항]]). 두 가지가 미정이었다 — ① 미선택 상태의 처리 시점,
② **상품마다 옵션을 다르게 적용하고 싶은 경우**. ②는 기존 확정과 긴장한다:
「문면은 마스터 소유 — 상품별 변주는 기본계약 연동뿐」([[도메인모델]] §3).
조건식은 상품 구분자 **값에 근거 있는** 갈림만 표현할 수 있어, 근거 없는
상품별 선택의 자리가 따로 필요하다.

## 결정

1. **참조 추가는 즉시 성립한다.** 옵션 미선택 검사는 **사용처 문서의 저장 시점** —
   미선택이 남아 있으면 저장 오류.
2. **옵션 기본 선택은 사용처 문서 마스터가 소유**한다.
3. **상품모델링에서 오버라이드할 수 있다** — 보통약관 페이지에서 상품별로,
   담보약관은 상품담보(탑재분)별로. 항상 공용조항 정의의 **유효 옵션 집합 안에서만** —
   자유 문장 수정이 아니다. 조립 해소 순위: 오버라이드 > 마스터 기본.
4. **공용조항 관리 페이지가 옵션별 오버라이드 사용처를 역조회**한다 (관계정보 뷰 확장).
5. 정의 수정으로 생기는 미선택(옵션 추가)·깨진 선택(옵션 삭제)은
   사용처 재검사([[ADR-0010-공용조항-참조바인딩]] 메커니즘)로 드러내고,
   해소 전 조립은 오류 + 좌표.

## 이유

- **자유 문장 수정 없이 상품별 요구를 수용한다** — 오버라이드는 정의된 옵션 집합 안의
  선택이라 통제된 변주다. 탑재 스냅샷의 필드 단위 수정과 같은 결.
- 조건식·벌 분리로 못 덮는 자리가 실재한다 — 값에 근거 없는 상품별 선택.
- 저장 시점 검사는 작성 흐름을 끊지 않으면서 조립보다 이른 발견 시점이다.

## 버린 대안

- **A. 오버라이드 없음** (옵션은 마스터 소유 고정, 상품별 차이는 조건식·보통약관 벌 분리) —
  원칙이 깨끗하다. 기각: 값에 근거 없는 차이는 조건식으로 표현 불가, 옵션 하나 차이로
  보통약관 벌을 분리하는 것은 과하다.
- **B. 참조 추가 시 선택 강제** — 발견이 가장 이르다. 기각: 문서 작성 흐름이 다이얼로그로
  끊긴다. 저장 시점 검사로 충분히 이르다.
- **C. 조립 시 오류로만 처리** — 기각: 발견이 늦고, 문서 저장이라는 자연스러운 검사
  시점을 버릴 이유가 없다.

## 결과와 감수하는 비용

- **「상품별 변주는 기본계약 연동뿐」의 예외 1호**가 생긴다 — 예외는 옵션 선택뿐임을
  유지하는 것이 이 결정의 경계다 (문장 수정 오버라이드로 확장 금지).
- 옵션 해소가 조립 규칙에 한 겹 추가된다 (오버라이드 > 마스터 기본).
- 오버라이드가 사용처를 늘린다 — 옵션 삭제·변경의 영향 범위에 상품모델링이 포함되고,
  관리 페이지의 역조회가 그 가시성을 담당한다.
