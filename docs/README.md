# terms-studio 문서

> 상태: 빈 뼈대 · 최종수정: 2026-08-29

이 프로젝트의 **유일한 문서 진입점**. 무엇을 어디서 읽고 쓰는지 여기서 정한다.

## 문서 지도

| 폴더 | 답하는 질문 | 언제 쓰나 |
|---|---|---|
| `00_시작/` | 왜 만드나 · 무엇을 다루나 | 프로젝트 전제. 여기부터 읽는다 |
| `01_기획/` | 무엇을 만드나 | 주제 하나가 문서 하나 |
| `02_UI/` | 어떻게 보이고 조작하나 | 기획이 화면으로 굳을 때 |
| `03_설계/` | 어떻게 만드나 | 코드를 쓰기 직전 |
| `04_실행/` | 언제 · 어떤 순서로 | 항상 열려 있는 작업판 |
| `05_QA/` | 맞게 됐나 | 인수기준·시나리오·회귀 |
| `06_결정/` | 왜 그렇게 정했나 | 되돌리기 어려운 결정마다 |
| `_템플릿/` | — | 새 문서를 시작할 때 복사 |
| `_archive/` | — | terms-lab 시절 옛 기획. **참고만, 개정 대상 아님** |

## 문서 규칙

- **문서 하나 = 주제 하나.** 커지면 쪼갠다.
- 모든 문서 첫 줄 아래에 **상태 배너**를 둔다 → `> 상태: 빈 뼈대 | 초안 | 합의 | 확정 | 폐기 · 최종수정: YYYY-MM-DD`
- 문서 간 참조는 위키링크 `[[문서이름]]`.
- 결정은 문서 본문에 녹이지 말고 `06_결정/` 에 ADR 로 남기고 본문에서 링크한다.
- 날짜는 **절대 날짜**로 쓴다 (`지난주` 금지).
- 옛 문서를 옮겨올 때는 **그대로 복사하지 않는다.** 지금 전제에 맞는지 다시 판단해 새로 쓴다.
